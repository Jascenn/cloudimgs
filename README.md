# Cloud Images

凌一使用的公开图片存储仓库，主要用于 PicGo、Typora 和 Markdown 文档中的图片外链。

## 用途

- 保存已经上传的博客、文档和工具截图。
- 为 Markdown 提供稳定的 GitHub Raw 图片地址。
- 保留历史图片链接，避免旧文档出现失效图片。

## 图片地址

仓库中的图片可以通过以下地址访问：

```text
https://raw.githubusercontent.com/Jascenn/cloudimgs/main/<文件名>
```

例如：

```text
https://raw.githubusercontent.com/Jascenn/cloudimgs/main/typora-icon.png
```

## 维护规则

- 不随意删除、改名或覆盖已有图片，旧文档可能仍在使用。
- 新增图片时保留 PicGo 生成的原始文件名，避免批量重命名。
- 本仓库只存放公开图片，不上传证件、账号截图、密钥或其他敏感内容。
- 本仓库不是软件源码项目，没有构建步骤和运行时依赖。
